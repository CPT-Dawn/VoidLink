# Security

VoidLink answers Bluetooth pairing requests on your behalf, so a flaw there matters.

## Supported versions

Fixes go into the latest release only.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/CPT-Dawn/VoidLink/security/advisories/new), not in a public issue. Include the version (`voidlink --version`), what you did and what happened.

Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.
